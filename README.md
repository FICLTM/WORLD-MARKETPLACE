# WORLD — Marketplace MVP

A premium marketplace for independent fashion, vintage, reworked clothing, art and objects.

## Run locally

1. Install Node.js 20+.
2. In this folder run `npm install`.
3. Run `npm run dev`.
4. Open http://localhost:3000.

## Main routes

- `/` — marketplace homepage
- `/world/ficl` — example seller World
- `/product/reworked-denim-jacket` — product page
- `/dashboard` — seller dashboard
- `/dashboard/products` — add-product flow

## Next build stage

Connect Supabase for users, seller Worlds, products, images and orders. Then connect Stripe Connect for marketplace payments and seller payouts.
